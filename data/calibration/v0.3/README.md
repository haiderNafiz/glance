# Glance Hair Perception Calibration Dataset v0.3

## Overview
- **Dataset Version**: `calibration-v0.3`
- **Total Samples**: 21 images + contact sheet
- **Generator Model**: FLUX.2-klein-4B
- **Status**: Accepted Calibration Baseline / Immutable

## Evolution from v0.2
Calibration v0.3 focused on fine category separability:
- Specifically targeted distinct boundaries between `LONG` (mid-back / scapula level) and `VERY_LONG` (waist level and below).
- Adjusted camera framing parameters to consistently capture lower torso landmarks.
- Finalized prompt structures utilized for the upcoming 100-image evaluation dataset generation.
