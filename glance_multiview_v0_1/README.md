Experiment: Multi-view Hair Generation v0.1

Objective:
Test whether FLUX.2 Klein reference conditioning can generate
multiple distinguishable viewpoints of one hairstyle.

Views:
FRONT
45L
90L
135L
REAR
135R
90R
45R

Findings:
1. Viewpoint separation improved after prompt/reference changes.
2. 90° and 135° views are now distinguishable.
3. Generated images remain visually related.
4. Hair geometry is not sufficiently consistent across views
   to claim multi-view reconstruction.
5. The result is better characterized as visually related
   viewpoint generation.

Conclusion:
Reference-conditioned generation provides useful viewpoint control,
but consistent reconstruction of a single hairstyle across views
remains an unresolved technical problem.

Next investigation:
Controlled multi-view hairstyle consistency.
